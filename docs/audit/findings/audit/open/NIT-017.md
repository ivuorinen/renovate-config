# `commitBody` duplicates the `:gitSignOff` preset

## Problem

`commitBody: "Signed-off-by: {{{gitAuthor}}}"` is byte-for-byte what the
built-in `:gitSignOff` preset sets. The `{{{gitAuthor}}}` field renders correctly
(the official preset uses the same template), so this is not a bug — just non-DRY.

## Evidence

## Impact

None functional.

## Fix

Optional — replace the literal `commitBody` with `extends: [":gitSignOff"]`.
