# CLAUDE.md/README describe commit scope as `chore(deps):` only

## Problem

`config:recommended` pulls in `:semanticPrefixFixDepsChoreOthers`, so runtime
dependency updates commit as `fix(deps): …` and only non-runtime as `chore(deps): …`.
The docs imply a uniform `chore(deps):`.

## Evidence

## Impact

Minor doc imprecision.

## Fix

Optional — note the `fix(deps):` vs `chore(deps):` split in CLAUDE.md/README.
