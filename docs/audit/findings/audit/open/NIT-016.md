# Harmless preset redundancies

## Problem

`:enableVulnerabilityAlerts` and `docker:enableMajor` re-assert defaults that
are already active (vulnerability alerts inherit the global `enabled:true`; Docker major
updates are on by default and `config:recommended` does not disable them).
`.github/renovate.json` sets `automergeType: "pr"`, which is already the default.

## Evidence

## Impact

None — harmless, arguably self-documenting.

## Fix

Optional removal. Kept for explicitness.

Migrated from v1 `nitpicker-findings.md` (Pass 2, 2026-06-26).
